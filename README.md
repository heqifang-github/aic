# AIC - AI Git 提交信息生成助手

`aic` 是一个基于 AI 的命令行工具，能够根据您的 Git 暂存区（staged）更改，自动生成简洁、专业的 Git 提交信息（Commit Message）。

它默认支持 **通义千问 (Qwen)** 模型，并强制生成符合 [Conventional Commits](https://www.conventionalcommits.org/) 规范的**中文**提交信息。

## 特性

*   🚀 **一键生成**: 只需运行 `aic`，即可自动分析代码变更并生成备注。
*   🤖 **智能暂存**: 自动检测未暂存的变更，询问是否暂存后继续。
*   🇨🇳 **中文优化**: 默认生成中文提交信息，符合国内开发习惯。
*   📝 **规范化**: 遵循 Angular 提交规范 (feat, fix, docs, refactor 等)。
*   🔧 **高度可配**: 支持自定义 API Key、Base URL 和模型名称。
*   ✨ **交互式体验**: 提供提交、编辑、重新生成等选项。

## 安装

您可以使用 npm 进行全局安装，以便在任何项目中使用：

```bash
npm install -g aic
```

或者在当前目录进行链接测试（开发模式）：

```bash
npm link
```

## 配置

首次使用前，您需要配置 AI 服务的 API Key。默认配置适配阿里云百炼（DashScope）的 Qwen 模型。

运行以下命令进行配置：

```bash
aic config
```

根据提示输入相关信息：

*   **API Key**: 您的 API 密钥（必填）。对于 Qwen，请在阿里云百炼控制台获取。
*   **Base URL**: API 基础地址。默认为 `https://dashscope.aliyuncs.com/compatible-mode/v1` (兼容 OpenAI 格式)。
*   **Model**: 模型名称。默认为 `qwen-plus`。

## 使用方法

### 方式一：自动暂存（推荐）

直接在项目目录中运行：

```bash
aic
```

程序会自动检测您的代码变更：

- 如果有**未暂存的变更**，会显示文件列表并询问是否暂存
- 如果已有**暂存区的变更**，直接生成提交信息
- 支持**混合模式**：有已暂存的文件时，可选择是否暂存其他文件，或仅提交已暂存的内容

**示例输出**：
```
检测到以下未暂存的更改：
 M src/ai.js
 M src/git.js

? 是否要暂存这些更改并继续？ (Y/n)
```

- 选择 `Y`：暂存所有变更并生成提交信息
- 选择 `n`：如果有已暂存的文件，仅对已暂存的文件生成提交信息；否则退出

### 方式二：手动暂存

您也可以先手动使用 `git add` 暂存特定文件：

```bash
git add src/feature.js
aic
```

程序将直接对已暂存的文件生成提交信息。

### 交互式提交

AI 生成提交信息后，您可以选择：

*   **使用此信息提交**: 直接使用生成的备注进行 `git commit`。
*   **编辑信息**: 在提交前手动修改生成的备注。
*   **重新生成**: 如果对结果不满意，可以让 AI 重新生成。
*   **取消**: 退出程序，不进行任何操作。

## 常见问题

**Q: 我可以只提交部分文件吗？**
A: 可以。先使用 `git add <file>` 暂存特定文件，然后运行 `aic`。如果有未暂存的文件，程序会询问是否暂存，选择 `n` 即可仅提交已暂存的文件。

**Q: 自动暂存会影响我的其他文件吗？**
A: 不会。自动暂存功能会：
- 显示所有未暂存的文件列表
- 询问您是否要暂存
- 尊重 `.gitignore` 规则
- 您可以选择拒绝自动暂存

**Q: 支持检测哪些类型的文件变更？**
A: 支持所有 Git 变更类型，包括：
- 新增文件（A）
- 修改文件（M）
- 删除文件（D）
- 重命名文件（R）
- 复制文件（C）

**Q: 如何切换到其他 AI 模型（如 GPT-4）？**
A: 运行 `aic config`，修改 Base URL 为 `https://api.openai.com/v1`，并将 Model 修改为 `gpt-4` 即可。

**Q: 生成的信息不准确怎么办？**
A: 您可以选择"重新生成"，或者选择"编辑信息"进行手动修正。AI 的准确度依赖于 Diff 的清晰程度。
